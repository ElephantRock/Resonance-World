# C3R G2 — causal organizational capability foundation

Status: **construction only / exploratory apparatus**. No scientific effect result, preregistered confirmatory campaign, authority promotion, or World integration is claimed.

## Why this work exists

W4/W5B show bounded value in partner-specific and preserved intact-pair capital, while W5A does not establish organization-owned learning across personnel replacement. H8 isolates a positive role/chair synthesis effect without showing added significance for typed history representations. This construction proposes one different manipulable mechanism: a candidate two-step workflow procedure, compiled from evaluator-graded experience and consumable by fresh members.

This is not a continuation or reinterpretation of W5A/H8/D2 results. Historical records remain immutable.

## Separation of domains

- **Source experience:** independently graded episodes from source agents; no hidden Field practice or evaluator truth is exposed to the compiler.
- **Procedure compilation:** reads only an admitted immutable evidence index; learns which of two opaque workflow orderings had greater descriptive success for an opaque context; abstains on insufficient support or ties.
- **Procedure execution:** purely transforms explicit task operands by an ordered sequence of public operations. It does not know whether an answer was correct.
- **World/evaluator truth:** a different harness grades the submitted value against a withheld expected answer. The World outcome law must not inspect treatment labels, memory, procedure identity, source history, or organization identity.
- **Evidence admission:** SHA-256 of an observation binds fields to a digest but is **not** proof that an agent did not fabricate the observation. For any real scientific run an independent evaluator owns both grading and the admission/locked source manifest. An agent must never be able to add outcomes to the admitted index.
- **Authority:** the existing AuthorityLedger remains the sole explicit-authority primitive. A candidate procedure cannot grant authority or become validated knowledge, policy, or truth. No Historical Substrate access is enabled.

## Current files and their limits

- tests/test_c3r_g2.py: credential-free tests for source binding, deterministic candidate fingerprints, abstention, holdout disjointness, and inability of a candidate to self-promote.
- src/resonance_world/c3r_g2_probe.py: credential-free deterministic fixture oracle, source and holdout input generator, blind two-proposal per-arm controller, A/B/C/D/D_MINUS outcomes, canonical noninferential probe report, and read-only CLI.
- tests/test_c3r_g2_probe.py: construction checks for honest C/D parity, matched members and work slots, data non-overlap, removal control, fixture determinism, and explicit noninferential labeling.

The numerical defaults in the compiler (2 episodes and 2 sources per plan) are **construction smoke-test floors**, neither a power calculation nor a materiality threshold. They cannot be used as confirmatory sample-size criteria.

## Proposed causal question

Under fixed model, tools, resources, organizational roster, evaluator, and independent task holdout, does executing a learned, externally evidenced workflow procedure improve performance beyond role assignment, equivalent raw history access, and the best budget-matched independent alternative?

The next experiment must measure four arms:

| Arm | Condition | Required control |
| --- | --- | --- |
| A | Budget-matched independent agents | Same number of task attempts / compute |
| B | Stable roles with a fixed non-learned procedure | Same roles and tool/step allowance as D |
| C | Raw evaluator-admitted history with access to the same candidate evidence | Same history token/record budget and role/chair structure as D |
| D | Compiled procedure from the same admitted development history | Same agents, task inputs, allowed operations and total work budget |

D should be compared to B and C as primary mechanism controls, with A as a wider usefulness baseline. The historical or raw comparator should receive an equivalent opportunity to interpret the record; do not design a deliberately incompetent raw-history controller to guarantee a D win. Any candidate procedure compilation cost must be measured and assigned consistently.

A held-out **procedure removal** condition (D without the compiled procedure, with a matched neutral replacement) will test whether a change in decisions explains any performance difference. Equalized compute alone is not a substitute for accounting for compilation or training costs.

## Pre-flight requirements

1. Choose an independently graded task environment in which a workflow choice can be learned, but where a general model's existing knowledge does not trivially reveal the answer.
2. Freeze evaluator code, treatment-integrity invariants, schema locks and data split. The compiler can observe only development outcomes, never a held-out label.
3. Replace the existing local A/B/C/D/removal **fixture wiring** with genuinely independent organizational development units, a demonstrated source-learning prerequisite, matched history opportunities and resource accounting. Current construction has no four-arm inferential design or sample power.
4. Inspect selection biases, context leakage, repeated-episode dependence, and organization-level experimental units.
5. Pre-register the estimand, unit of randomization, paired/disjoint structure, multiplicity, power, minimum analyzable N, CI method, independent replication, stopping/missing-data rules, and prospectively justified materiality classification.
6. Run only local deterministic construction/probe tests first. Later stochastic/provider execution needs separately frozen samples, strict send caps and explicit human authorization.
7. If G2 is supported, test fresh-member usage and then full succession as separately gated G3 research. Do not build G4 market systems yet.

## Known failure modes to enforce

- Never let the compiler receive World truth, successful-answer labels from future missions, or private Field/agent practice.
- Do not count correlated tasks from one organization as independent experimental organizations.
- Digest validity is not evaluator authority or evidence-of-effect validity.
- A descriptive paired success difference is **not** a statistically accepted result.
- Fixed two-step arithmetic examples are a test apparatus, not evidence of autonomous organizational learning or persistent institutions. In the fixture, C and D intentionally produce identical task outcomes, and synthetic source feedback was scripted rather than learned.
- Neither this branch nor its CI permits modifying W*/H*/D* historical artifacts, enabling Historical Substrate, spending provider tokens, or altering scientific registry states.

## Entry/exit conditions

**Entry:** existing default branch and untouched W4/W5/H8 evidence; new isolated research branch with no provider authorization.

**Exit for construction:** Ruff/pytest on relevant files, an independent code review, and a clear prospective four-arm study design. It does **not** grant G2.

**Exit for G2 science:** frozen powered confirmatory contrast on a new cohort + independent replication and mechanism ablation; no claims beyond supported scope.

## Additional G1-to-G2 construction probe

The initial scripted source fixture and its honest C/D tie remain intact. The newer
`src/resonance_world/c3r_g1_acquisition.py` now performs a distinct, feedback-driven
source-acquisition construction test: two learners per context propose actual plans
before the evaluator grades them, each learner receives only its own post-action
Boolean feedback, and G1 qualification happens on separate public operands.

Run `python -m resonance_world.c3r_g1_acquisition` for an explicitly noninferential
canonical JSON report. Its controls include prebalanced fresh-source starting plans,
wrong/duplicated feedback rejection, split/payload-disjoint holdouts, and a separately
evaluated A/B/C/D/D_MINUS destination comparison. The competent raw-history C and
compiled D still intentionally tie under the simple sufficient statistic. The new
tests and `research/c3r_g2/FEEDBACK_ACQUISITION_PROTOCOL.md` describe all boundaries.

**Crucially:** feedback-policy adaptation is a hand-coded local algorithm; this does
not validate acquisition by an actual model/agent, nor change the source's schema,
nor establish independent organization-level G2 uplift. The construction has one
organization-level unit and no powered confirmatory inferential claim. No provider
invocation or authority/registry promotion is authorized.

## Default-off model port preflight

An additional isolated `src/resonance_world/c3r_g1_model_boundary.py`
declares `ModelChoicePort`, `ModelChoiceRequest`, `ModelChoiceCompletion`,
`ModelCohortLock`, and a G1 runner that receives an externally injected
model port. There is **no bundled provider client or default live execution**.

The runner provides development-only feedback to the trained port and compares
it against a fresh port on separated qualification inputs. Invalid output,
adapter exceptions, invalid return types, and overruns of adapter-reported
send caps are counted explicitly rather than silently discarded. Qualification
grades are not fed back to either port. It stores no raw prompts or outputs
in canonical reports, only status and bounded hashes/usage. This is a fixture
**API boundary**, not independent evaluator security or source-scientific
acquisition; an injected adapter can still be untrusted.

See `research/c3r_g2/MODEL_PREFLIGHT.md` for a provider readiness checklist,
external evaluator-attestation requirements, transport-enforced send caps,
fair fresh baseline requirements, analyzable yield, and prohibited scientific
promotions. Live model invocations remain a separate authorization gate.

offline. See `research/c3r_g2/LIVE_SMOKE_RUNBOOK.md`.
