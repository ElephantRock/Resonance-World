# W5A — Minimal Organizational-Learning Substrate

Status: **ARCHITECTURE ONLY — NO INSTITUTIONAL-CAPITAL CLAIM**

W5A introduces an organization-owned state layer after W5-00 established that none existed.

The substrate contains:

- persistent `organization_id` independent of current members;
- replaceable member roster;
- organization-owned episode history;
- context-indexed strategy attempts/successes;
- last successful pair history for continuity routing;
- independent organization-memory reset.

The organization controller may use retained memory to choose among generic routing policies (`specialist`, `balanced`, `continuity`). A retained procedure can therefore affect how a completely new roster is deployed.

The environment remains blind to organization identity, age, episode count, strategy history, or institutional memory. It evaluates only Field-derived individual state, mission requirements, role actions, and a deterministic seed through the W4 joint environment.

W5A does not establish that organizations learn useful memory. It only makes that hypothesis operational for W5 while preserving the causal separation between memory and outcome law.

Resonance Field is unchanged.
