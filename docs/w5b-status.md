## W5B-01 — Modular Pair Preservation

For each of three fixed pairs per Field, capture a W4-developed `PairModule` and compare:

1. intact module state;
2. the exact same two members with all relationship state reset;
3. a deterministic stranger pair as a secondary composition baseline.

Primary effect:

`intact module - same members / relationship reset`

A positive replicated effect establishes **state modularization**: W4 social state survives capture and reinstantiation as a reusable module.

## W5B-02 — Module Succession

Replace one member of each module. Compare the same survivor and the same replacement agent under:

1. the state W5B-00 legitimately permits to survive replacement;
2. a completely fresh relationship state.

W5B-00 explicitly drops old partner-specific models and old pair-owned episodes. Only the surviving agent's partner-independent general-teamwork state may remain.

Primary effect:

`replacement pair with legitimately inherited state - same replacement pair / fresh relationship state`

A positive replicated effect is evidence for **social-state inheritance across personnel change**. A null result means module value remains bound to intact membership.

## W5B-03 — Cross-Module Composition

Two intact modules are composed sequentially on a mission requiring both module-specific stages. Success requires both stages to succeed.

Comparison:

`two intact modules - same four agents with both module relationship states reset`

There is **no inter-module coordination state** in W5B. This experiment tests whether independently preserved modules compose as reusable capability units; it does not test inter-module relationship capital.

## W5B-04 — Module Library Accumulation

Each Field uses the same six module-member agents at every library size. The treatment is only how many of the three pair modules retain their captured W4 relationship state.

Registered library sizes: 0 / 1 / 2 / 3 modules.

Primary effect:

`three-module library - zero-module library`

Agent count, mission set, communication budget, and destination draws remain fixed.

## W5B-05 — Post-freeze unseen replication

## Interpretation hierarchy

If W5B-01 replicates but W5B-02 is null, the supported claim is **organizational preservation of intact social capital**, not institutional inheritance.

If both W5B-01 and W5B-02 replicate positively, the stronger supported claim is that some social state can be inherited across personnel change.

W5B-03 and W5B-04 then determine whether preserved modules compose and accumulate into a reusable organizational capability portfolio.
