## Frozen experiments

### W8-01 — Source reserve and composition efficiency

- primary cap: 2 active external rights per 12-agent source Field;
- sensitivity: 1 and 3;
- raw source loss and organization performance reported separately;
- composition-efficiency loss is measured against the highest-performing feasible
  allocation with aggregate source loss no greater than the capped source loss +0.2 pp;
- primary gate: source loss <=2 pp and organization performance no worse than -2 pp
  versus unrestricted rival recruitment.

### W8-02 — Circulation duty-cycle frontier

- 24-window horizon;
- permanent recruitment;
- 4 external : 2 home, offsets `[0, 2, 4]`;
- 3 external : 3 home, same offsets;
- one explicit role-specific practice unit per completed external service window;
- returned state is evaluated at home whenever the agent is not externally active;
- gate: at least one duty cycle preserves organization service within -2 pp of permanent
  recruitment while mean source loss is <=2 pp.

### W8-03 — Source dividend and native replacement contingency

- primary source dividend: 50% of winning contract price;
- sensitivity: 0% and 100%;
- development cost: 12 dividend credits per funded native Field lifecycle cycle;
- one preregistered target vacancy per recruited source Field, where available;
- comparison: extracted ecology versus identical vacancy-only ecology;
- Field source is not patched; World wraps only exit/requester/candidate availability and
  calls Field's production lifecycle runner with the same lifecycle corrections as the
  source CLI;
- replacement never receives a target skill or departed-agent phenotype;
- classification thresholds:
  - recovery source loss <=2 pp;
  - ecological contingency: extracted-vs-vacancy successor cosine distance >=0.10;
  - capability-replication diagnostic: successor/source-target cosine >=0.95 and >=80%
    dominant-skill match when contingency is below 0.10;
- if native targeted-vacancy execution proves impossible without changing Field's
  developmental/outcome law, the registered result is an architectural limitation.
