# G1 — قرار Internal-First لمنع الاختناقات (2026-10-23)

**قرار معماري للمشروع:** العمل محصور داخليًا. لا حاجة إلى مدقّق مستقل أو خارجي، أو شاهد خارجي، أو جهة أرشفة تابعة لطرف ثالث. لا يمثّل هذا القرار موافقة على إنفاق جديد أو تشغيل نموذجي حي، ولا قبولًا علميًا لنتيجة G1. [PR #310](https://github.com/ElephantRock/Resonance-World/pull/310) يظل Draft.

## الدافع

زادت آلية G1 التجريبية السابقة مراحل الاعتماد المتسلسل إلى Evaluator → Custodian → Witness → Archive مع بقائها داخل بيئة GitHub واحدة. هذه السلسلة تضيف انتظارًا ونقاط فشل دون ضمان استقلال مؤسسي، وتخالف الهدف التشغيلي للمشروع. يُفضّل التحقق المحلي المؤتمت وأصغر حاجز ضروري للحفاظ على حدود التدريب/التأهيل.

## المسار المعتمد: Internal Checkpoint

1. **التسجيل الداخلي:** خطة G1 ثابتة، ومعرّف تشغيل فريد، ومجلد خاص للعملية بصلاحيات 0700. لا توجد سلطة توقيع أو خدمة خارجية.
2. **التدريب:** توثيق 16 محاولة مصدر وفق الخطة بإيصالات Ed25519. تُحجب خريطة الإجابات الخاصة عن العميل؛ تُتاح تغذية راجعة للتدريب فقط.
3. **حاجز آلي واحد:** يتحقق المقيّم من الإيصالات الستة عشر ويكتب ملف بصمة خاصًا بصلاحيات 0600 وبإنشاء حصري O_EXCL، مع fsync للملف والمجلد. يحوي البصمة، ومعرّف التشغيل، وبصمة الخطة، والمفتاح العام، ولا يحوي خريطة الإجابات.
4. **التأهيل:** ينفتح تلقائيًا بعد نجاح التثبيت. لا يلزم طلب موافقة أو إيصال شاهد أو أرشيف. 24 محاولة تأهيل؛ تُحجب الدرجات حتى إغلاق الأربعين محاولة.
5. **الإغلاق:** يُراجع ملف التثبيت مقابل الإيصالات أول مرة قبل التأهيل ومرة عند الإغلاق، وتُتحقق سلسلة التوقيع ومقام 16+24. لا يُقبَل فقد أو تغيير أي سجل. حالات not_sent تبقى في الحساب.
6. **ما بعد الإغلاق:** التحليلات المشتقة والتقارير والتوثيق تعمل من نسخة مغلقة، ولا تتدخل في التنفيذ المباشر.

## سياسة تجنب الاختناقات

| عنصر | السياسة |
| --- | --- |
| طلب موافقة بشرية أو من مدقّق مستقل | غير مطلوب |
| Custodian / Witness / External Archive | مسارات تراثية غير إلزامية، ليست ضمن Internal Checkpoint |
| حاجز مصدر ما قبل التأهيل | حاجز داخلي واحد مطلوب لصحة الفصل التجريبي |
| التحقق من البصمة | مرتان حول التأهيل بدل التحقق الكامل في كل محاولة |
| تجارب مستقلة | يمكن تشغيلها بالتوازي بشرط عزل المجلدات ومعرّفات التشغيل |
| ترتيب محاولات التجربة الواحدة | يحترم الجدول المجمّد؛ لا تُضحّى سلامة التصميم لتسريع التنفيذ |
| مخرجات قابلة للاشتقاق | تحليل لاحق أو مسار غير حاجب، لا يفرض سلطة موافقة |
| فساد ملف التثبيت أو تكرار معرّف التشغيل | إيقاف آمن مع سبب واضح، ومنع الاستبدال الصامت |

منع الاستبدال العرضي وfsync ليسا تخزينًا غير قابل للتغيير أمام مسؤول نظام ذي صلاحيات. وجود توقيع صادر عن المقيّم لا يعني وجود مقيّم مستقل. يظل إثبات G1 العلمي مرتبطًا بضبط المقارنات والتوزيع المسبق، وعزل الجلسات، وصحة درجات الإجابة، وتكافؤ الرموز والحوسبة، وصدق سجلات المزود عند التشغيل الحقيقي.

- src/resonance_world/c3r_g1_crossed_internal_lock.py — قفل داخلي محلي صالح للتحقق دون طرف آخر.
- src/resonance_world/c3r_g1_crossed_local_evaluator.py — وضع داخلي صريح يفتح التأهيل تلقائيًا بعد التجميد.

مثال محاكاة دون مزود:

    mkdir -m 700 -p /private/g1-internal-locks
    python -m resonance_world.c3r_g1_crossed_local_evaluator \
      --run-id UNIQUE_NEW_RUN_ID \
      --target-seed-file /private/target.hex \
      --signing-seed-file /private/evaluator.hex \
      --internal-checkpoint-dir /private/g1-internal-locks

تُنشأ بذور المفاتيح بصورة داخلية وتُحفظ ملفاتها بصلاحيات 0600. لا تحتوي هذه الوحدة على مُرسِل طلبات نموذج حي.

## تشغيل دفعات G1 دون حاجز مركزي (2026-10-23)

بُني منسّق داخلي اصطناعي محدود السعة يجمع تشغيلات مستقلة من
CrossedLocalEvaluator، دون تغيير حاجز البصمة الأساسي لكل تشغيل.
المواصفة في G1_INTERNAL_BOUNDED_BATCH_EXECUTION_20261023.md
والشيفرة في src/resonance_world/c3r_g1_crossed_internal_batch.py.

لا توجد موافقة عالمية متسلسلة: لكل تشغيل مطالبة تشغيل حصرية
ومجلد بصمة مستقل؛ ويقتصر الطابور المرسل على ميزانية محددة،
بينما يتقدم تشغيل ناجح حتى لو تعطل تشغيل آخر. يدعم المنسّق
الإيقاف عند حد قبول تشغيلات جديدة واستكمال **التي لم تبدأ فقط**.
أي تشغيل حُجز ثم انقطع يُعرض للمراجعة الداخلية دون إعادة
محاولاته أو احتساب نجاح غير متحقق. لا تنشر الملخصات العامة
درجات التأهيل قبل إغلاق السجل.

هذا إنجاز بنيوي للاختبار المحلي لا قياس لتسريع النماذج الحقيقية:
Threads غير قابلة للإنهاء القسري؛ مهلات التشغيل الصلبة
وحدود تكلفة المزود لا تزال خارج نطاق هذا المنسّق الاصطناعي.
لا استدعاءات مدفوعة، ولا اعتماد خارجي، ولا قبول علمي جديد.
