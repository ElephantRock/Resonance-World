# D2 confirmatory plan v0.1

Status: prospective confirmatory design; zero provider calls at design freeze.

## Scientific question

Can the R2 stochastic model-mediated development mechanism reproduce a locally developed specialist capability in fresh destination Fields, beyond description-only practice, while preserving at least 90% of source-developed accuracy and without exporting source-private learned state?

This is a single-model synthetic individual-agent confirmatory study. It is not a weight-learning, cross-model, team, naturalistic, market, composition, or environment-spawning claim.

## Prospective provenance

D2 originated as `posthoc_motivated` after D1/D1b. Independent acceptance of D1/D1b is already recorded. D2-0 R1 was not learnable; the prospectively revised R2 substrate passed its source-learnability gates and is development-only calibration, never confirmatory evidence.

The confirmatory intervention is the frozen R2 mechanism:
- Z.AI `glm-5-turbo`;
- temperature 0.8; thinking disabled; JSON action contract;
- four actions: KAPPA, MICA, ORBIT, VELA;
- one hidden local-policy family: two undisclosed controlling feature coordinates, each thresholded at 4, plus an undisclosed one-to-one four-action relabeling;
- 40 source-local and 40 destination-local development cases per Field pair;
- five batches of eight cases;
- outcome-bearing local feedback for source/reproduced;
- equal-call unlabeled practice for description-only;
- 32 held-out evaluation cases;
- Capability Artifact v0.2 production-conditions boundary;
- no evaluation feedback;
- no Historical Substrate.

Only fresh confirmatory identities/seeds/cases are used. No R1/R2 calibration pair is reused.

## Experimental unit and pairing

Experimental unit: one fresh confirmatory Field pair sharing one hidden local policy.

Within each pair:
1. `source_developed`: source-local development + labeled feedback.
2. `reproduced`: destination-local development + the public Capability Artifact + labeled feedback.
3. `description_only`: the same destination-local practice schedule with no labels/outcome feedback.
4. `fresh`: no development.

All four arms are evaluated on the same 32 held-out cases for that pair. Source and destination development feature tuples are exactly disjoint; all development tuples are disjoint from evaluation tuples.

Attempted confirmatory pairs: **360** fixed.
Minimum analyzable pairs: **330**.
No replacement pairs and no outcome-adaptive sample-size increase.

A pair is analyzable only when all four arms complete the frozen logical-call contract and all pair-level integrity checks pass. If fewer than 330 pairs are analyzable, the campaign is D2-S4 (scientifically unclassifiable). No imputation is allowed.

## Primary estimands and threshold provenance

All scores are held-out accuracy proportions on the 32 frozen evaluation cases.

### P0 — source capability development

`P0_i = source_developed_i - fresh_i`

SESOI: **+0.10** (10 percentage points).

Primary null: `mean(P0) <= 0.10`.
Primary alternative: `mean(P0) > 0.10`.

Threshold class: `conventional_materiality`. It is chosen prospectively as a nontrivial accuracy gain on a four-action task; it is not estimated from the favorable R2 P0 effect.

### P1 — reproduction beyond description

`P1_i = reproduced_i - description_only_i`

SESOI: **+0.10**.

Primary null: `mean(P1) <= 0.10`.
Primary alternative: `mean(P1) > 0.10`.

Threshold class: `conventional_materiality`, chosen identically to P0 and not from the favorable R2 P1 effect.

### P2 — reproduction fidelity

The conventional fidelity criterion is **90% preservation of source-developed accuracy**, continuing the D1/D1b fidelity concept without importing D1's absolute deterministic margin.

Define:

`P2_90_i = reproduced_i - 0.90 * source_developed_i`

Primary null: `mean(P2_90) <= 0`.
Primary alternative: `mean(P2_90) > 0`.

Because the contrast is linear, `mean(P2_90) > 0` is equivalent to aggregate reproduced accuracy being greater than 90% of aggregate source-developed accuracy when source accuracy is positive.

Threshold class: `conventional_fidelity`. The 90% criterion is fixed before confirmatory outcomes and does not use the observed R2 reproduced-source effect.

The raw `reproduced - source_developed` difference and the aggregate fidelity ratio are also reported but do not replace the registered P2 test.

## Alpha, multiplicity, tests, and intervals

One-sided alpha: **0.05**.

Primary family uses fixed serial gatekeeping:
`P0 -> P1 -> P2`.

P1 can enter the confirmatory gate only if P0 passes. P2 can enter only if both P0 and P1 pass. This preserves familywise type-I error at 0.05 for the ordered mechanism claim.

Each primary contrast uses the preregistered large-sample paired normal test across Field pairs:
- point estimate: arithmetic mean of the paired contrast;
- standard error: sample SD / sqrt(N);
- one-sided p-value against its registered threshold;
- one-sided 95% lower confidence bound;
- two-sided 95% normal confidence interval.

All three raw p-values and Holm-adjusted p-values are reported as diagnostics; classification authority remains the serial gatekeeping contract.

Sensitivity analysis: deterministic paired bootstrap with 50,000 resamples and frozen RNG seed 2026081516, reporting percentile 95% intervals for P0, P1, raw reproduced-source, P2_90, and the aggregate reproduced/source fidelity ratio. Bootstrap results cannot rescue a failed primary gate.

## Power and minimum N

R2 is used only for variance planning; its favorable effect estimates are not used as expected confirmatory effects.

Frozen R2 paired SDs:
- P0 SD = 0.2619892991;
- P1 SD = 0.2878685526;
- P2_90 SD = 0.3092419447.

Power uses the normal approximation with one-sided alpha 0.05 and target power 0.90.

For P0/P1, the planning alternative is 0.20 total effect, i.e. 0.10 above the 0.10 SESOI:
- P0 requires approximately 59 analyzable pairs;
- P1 requires approximately 71.

P2 drives the design. The power alternative assumes reproduced accuracy equals source accuracy (true fidelity ratio 1.0) and uses source accuracy 0.50, the prospectively fixed R2 source-readiness floor rather than the observed R2 mean. Under that conservative alternative, expected `P2_90 = 0.05`; R2 SD 0.3092419447 requires approximately 328 analyzable pairs for 90% power.

Minimum analyzable N is therefore **330**. We attempt **360** fixed pairs, allowing up to 30 incomplete/unusable pairs without changing the inferential contract. At N=330 the normal-approximation P2 planning power is approximately 0.902.

## Capability Artifact / export boundary

Capability Artifact schema remains v0.2. It may carry production conditions and public source evidence, but never:
- source agent identity;
- source conversation state;
- source private strategy/memory;
- source development examples;
- source or environment seeds;
- hidden policy/truth;
- evaluator answers;
- confirmatory holdout cases/answers.

Each pair's artifact is audited against its concrete source identity, source/pair seeds, source example IDs, and hidden truth token before destination reproduction.

## Evaluator separation

The provider runner emits frozen parsed actions, evaluator-private holdout truth, call provenance, and integrity metadata. It does not classify D2.

`scripts/evaluate_d2_confirmatory.py` is frozen before provider execution and is the only confirmatory classifier. It recomputes all final scores from frozen actions/truth, verifies provider-runner scores and all integrity/accounting gates, applies the registered statistical contract, and writes the result.

Evaluator reruns over identical provider output must be byte-identical except for no wall-clock timestamp in the scientific result.

## Stopping and missingness

Fixed 360 attempted pair tasks. No interim outcome analysis, efficacy stopping, futility stopping, sample-size re-estimation, threshold retuning, or confirmatory rerun.

Transport retries follow the frozen call contract. A pair that cannot complete after allowed retries is retained as a failed attempted pair and is not replaced. Complete-case analysis is permitted only if N >=330. Otherwise S4.

Any cohort-lock mismatch, artifact leakage, evaluation feedback, model drift, arm call-count mismatch, provider-output/evaluator inconsistency, or other treatment-integrity violation yields D2-S4 rather than a negative mechanism result.

## Prospective classification

- D2-S0: integrity classifiable, N>=330, P0 fails.
- D2-S1: P0 passes; P1 fails.
- D2-S2: P0 and P1 pass; P2 fidelity fails.
- D2-S3: P0, P1, and P2 all pass under serial gatekeeping.
- D2-S4: apparatus/treatment-integrity failure or N<330.

No D2 result promotes the registry automatically. Any post-result promotion requires a distinct Acceptance-plane actor (`proposer_id != acceptor_id`).

## Replication requirement / claim ceiling

Even D2-S3 is discovery support only for this registered single-model synthetic individual-agent stochastic mechanism. It requires a fresh D2 replication before `internally_replicated`.

It does not establish cross-model/provider reproduction, model-weight learning, semantic/naturalistic transfer, team/swarm/relationship/institution reproduction, capability composition, market viability, environment spawning, or production Historical Substrate.

Production/default Historical Substrate remains OFF.
