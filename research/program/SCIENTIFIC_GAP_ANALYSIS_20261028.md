# B. Scientific Gap Analysis (2026-10-28)

Status: **realignment deliverable B.** Derived from the Program
Evidence Map (deliverable A). No experiments proposed here beyond the
single selection forwarded in deliverable C. The three-way distinction
is enforced throughout: UNMEASURED ≠ did-not-meet-gate ≠ negative
evidence.

## The convergence finding (why gap 1 is first)

Three independent program lines, on different substrates and harnesses,
converged on the same unresolved question:

- **H-series (bench harness):** raw structured history is the positive
  channel (H1–H4); every layer built OVER it failed to add value
  (H5 negative; H8 no aggregate improvement; H6/H7 contradictory).
- **W-series (World harness):** every organizational-memory
  representation failed (W5A null replicated; W5B-02 null); the only
  durable collective asset is INTACT pair membership (W4, W5B-01/04).
- **Piano (institutional harness):** four consecutive near-misses at
  the +3pp materiality gate with the documented diagnosis that the
  bottleneck is memory FORMATION QUALITY — "an information-quality
  problem in institutional memory formation, not an action-selection
  or task-geometry problem" — and a non-monotonic information curve
  ("evidence quantity alone is not a monotonic solution").

Common question: **can ANY organization-owned mechanism condense
experience into a form that beats competent members' direct use of the
same evidence — and survive turnover?** Nobody has ever run the clean
discriminating comparison: identical, externally graded evidence in
every arm; one arm gets the organization-level condensate. The
C3R-G2 construction designed exactly this (A/B/C/D + removal) and never
ran it, because its pre-flight demanded a model-induction
prerequisite that the acquisition program has now closed as
operationally unattainable. The realignment (external evidence
admission) removes that blocker without touching the design.

## Ranked gaps

### Gap 1 — Organization-owned knowledge vs equal-information raw evidence (Agents→Organizations)
**Status: UNMEASURED (the discriminating contrast never ran).**
Prior evidence does not settle it: H8 tested representation layers in
a single-decisioner bench (not an organization executing a shared
procedure); W5A tested routing statistics (its own representation, no
graded-evidence channel); Piano 5-series tested passive structural
memory (no compiled actionable procedure). The repo's own reviewed
four-arm design exists (docs/c3r-g2-construction.md). **Selected as
deliverable C.**

### Gap 2 — Institutional memory materiality across turnover (Organizations→Institutions)
**Status: did-not-meet-gate, directionally consistent, 0.04–0.5pp short
(Piano 5/5B/5C/5D); UNMEASURED for the H-style raw-history channel
inside an institutional harness.**
What would settle it: (a) if gap 1's winner is the compiled procedure,
test ITS turnover (the gated successor study); (b) independently, test
whether the H-style admitted structured history channel passes the
same +3pp materiality gate under 100% turnover in the Piano harness —
two proven-positive threads (H2–H4 turnover survival; Piano primitives)
that were never connected. Not selected now: it is downstream of gap 1
by the program's own causal-dependency rule, and the owner asked for
one experiment.

### Gap 3 — Composition/coordination beyond intact pairs (Agents→Organizations)
**Status: did-not-meet-gate / inconsistent (W5B-03 replication inside
band; W6-06 transfer 1/3 paths; W7-01 benefit in 1/3 orgs; W9-04
coalition zero).**
The only replicated multi-member positive is the two-agent swarm under
an explicit destination law. Nothing replicated scales collective
capability beyond intact pairs. Not selected: no reviewed mechanism
candidate with a discriminating design is on the shelf; gap 1's
experiment (role-structured arms) generates evidence relevant here
anyway.

### Gap 4 — Source-protection vs service vs regeneration (economic layer)
**Status: negative/replicated (W8 regimes; W9 mechanisms failed
jointly; MSC estimator calibration positive).**
The tradeoff frontier is mapped; no regenerative mechanism passed.
Not selected: the owner's priority ordering places capability-origin
questions first, and this line needs a new mechanism family rather
than a discriminating contrast between existing ones.

### Gap 5 — Confirmatory behavioral agent memory (Models→Agents)
